# Réponses aux questions

1. `git add` prépare les modifications choisies. `git commit` les enregistre dans l'historique local du projet.

2. Le dépôt local se trouve sur mon ordinateur. Le dépôt distant se trouve en ligne, par exemple sur GitHub.

3. Trois petits commits sont plus faciles à comprendre et à corriger, car chacun décrit un changement précis.

4. Le fichier `.gitignore` indique à Git les fichiers à ne pas ajouter au dépôt. Par exemple, un fichier contenant un mot de passe ou un token secret ne doit jamais être versionné.

5. Du moins clair au plus clair : « modif », « correction page », puis « tp01: ajoute la liste des loisirs ». Le dernier précise l'action effectuée.
